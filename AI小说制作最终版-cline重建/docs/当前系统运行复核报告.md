## 5. 发现的问题与修复

首次回归发现两个实现问题：

1. 快照对象使用独立构造方式时，目标目录内仍可能保留模板快照的空值字段，导致参数没有进入实际快照。
2. PowerShell 中文文件名的 Unicode 码点映射中，“照”被错误写成“片”，脚本尝试读取不存在的 `项目快片.json`。

处理结果：

- 初始化脚本改为读取复制后的正式模板快照对象，逐字段更新后写回同一文件；
- 修正快照文件名码点为 `项目快照.json`；
- 保留脚本末尾的落盘读取和字段逐项校验，避免静默生成错误状态。

修复后的完整回归已通过，快照输出为：

`SNAPSHOT=悬疑|心理悬疑|长篇|冷峻克制|起点|成年读者`

## 6. 行为与边界复核

| 场景 | 结果 |
|---|---|
| 目标目录不存在 | 创建并初始化项目 |
| 目标目录已存在 | 脚本拒绝覆盖 |
| 缺少模板目录 | 脚本停止并报告错误 |
| 未确认的故事设定 | 不写入锁定事实或正文 |
| 参考目录 | 只读分析，不作为写入目标 |
| 初始化参数落盘异常 | 末尾校验会使脚本失败，不继续报告成功 |
| 不同项目混用 | 依赖项目唯一根目录和项目索引规则阻止跨项目读取 |

协议级行为、连续生产状态机、恢复顺序和异常停止规则详见 `docs\行为复核报告.md`。
