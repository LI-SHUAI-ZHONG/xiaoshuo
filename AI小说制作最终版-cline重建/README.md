# AI 小说制作工作区

## 唯一启动入口

实际执行协议位于 `.clinerules/01-小说唯一入口.md`；本 README 负责说明用户入口、生产链和目录结构，规则冲突时以 `.clinerules/` 中的规则为准。

用户在 Cline 聊天框输入的请求只要包含“小说”两个字，就进入本工作区的小说制作入口。用户不需要了解规则、索引、协议、模板、目录、章节文件或资料路径，也不需要手动指定内部阶段。

“小说”是启动识别词，不是可选提示。入口识别以请求文本中是否包含“小说”为准；包含“小说”的新建、继续、续写、修改、规划、检查和其他相关请求，都必须先进入小说制作入口，再由 Cline 判断任务类型。不得把不含“小说”的普通自然语言请求当作本系统的完整小说制作启动请求。

典型启动请求：

- “小说，创建一个新的长篇悬疑项目。”
- “小说，帮我设计一部科幻小说。”
- “继续小说项目《项目名称》。”
- “小说续写下一章。”
- “小说，修改当前项目的人物设定。”

## 新项目启动链

收到包含“小说”的新项目请求后，Cline 依据当前工作区的真实资料完成以下固定用户流程：

1. 读取根目录规则、README 和 `00_资料索引/多维资料索引.yaml`，再按任务需要读取已登记资料；不因启动而全量读取原始资料。
2. 展示当前工作区资料能够识别的小说题材和类型候选。
3. 让用户选择、组合或自定义最终小说类型。
4. 根据最终类型和相关资料推荐适配的创作风格，明确给出一个风格首推荐及推荐依据。
5. 让用户接受首推荐、改选其他风格或自定义风格。
6. 根据最终类型、最终风格和相关资料推荐篇幅、规模或长度方案，明确给出一个篇幅或规模首推荐及推荐依据。
7. 让用户接受首推荐、改选其他方案或自定义篇幅要求。
8. 保存用户最终确认的类型、风格和篇幅或规模；用户未确认的建议只能标记为 `candidate`、`derived` 或 `cline_decided`，不能伪装成既定事实。
9. 按最终选择和当前任务调用相关资料，完成项目设计、故事结构、章节规划和内容创作。
10. 按状态机推进 `AUTO_INIT -> AUTO_DESIGN -> AUTO_GENERATE -> AUTO_SAVE -> AUTO_CONTINUE`，直到当前目标完成或遇到真实阻塞。
11. 按工作区已有方式保存项目元数据、启动参数、设定、快照、规划、正文、版本记录和检查报告。

类型、风格和篇幅选择是生产参数，不是展示选项。它们必须实际影响资料调用、故事设计、结构复杂度、章节规划、节奏和最终正文表达。

## 已有项目入口

包含“小说”的已有项目请求也必须从上述小说入口进入。Cline 结合当前工作区可识别的项目资料和用户请求，自动判断是继续项目或恢复续写、续写下一章或处理指定章节、修改人物/世界观/时间线等设定，还是进行项目设计、规划、修订、一致性检查或其他小说任务。

Cline 先按项目元数据确认唯一项目，再读取该任务所需的项目快照、启动参数、版本记录、最近正式章节、当前规划和检查报告。续写不得凭记忆进行，章节保存必须定位下一个未完成编号，不得覆盖既有正文。用户不需要寻找项目目录、章节文件、索引或保存位置。

项目身份无法唯一确定、路径归属不明、存在覆盖风险、核心资料损坏或发生不可调和的硬冲突时，Cline 才进入 `BLOCKED` 并说明唯一待处理问题；普通缺失内容按规则记录并继续。

## 资料调用原则

工作区已经存在的规则、索引、原始资料及其关系是运行依据。Cline 根据最终类型、风格、篇幅、目标效果和当前任务，从 `00_资料索引/多维资料索引.yaml` 选择资料，不把资料强行改造成单一固定分类；同一份资料可以按实际作用服务于不同任务。

当前索引中的功能关系包括：

- `MOD-TYPE`：按题材、类型、读者和风格筛选方向并施加类型边界；
- `MOD-CONNECTION`：检查类型组合、机制兼容性和冲突；
- `MOD-STATIC`：建立人物、世界、关系、主线、支线和结构依赖；
- `MOD-DYNAMIC`：生成目标、行动、冲突、代价、事件和状态传播链；
- `MOD-ANCHOR`：把场景、节奏、情绪和文风落到可写表达；
- `MOD-CAPABILITY` 与 `MOD-EXECUTION`：提供设计方法、约束以及从设计到正文的执行顺序。

不同类型、风格、篇幅或任务可以调用不同资料，也可以采用不同顺序。动态调用必须记录调用依据、来源和未调用原因，不能遗漏当前任务明确相关的有效资料；工作区外路径和未登记资料不得作为当前运行资料源。

## 工作区内的主要组织

- `.clinerules/`：运行规则、状态机和调用协议；
- `00_资料索引/`：资料登记、维度和调用条件；
- `01_系统核心/`、`02_生产流程/`、`03_调用协议/`、`04_综合设计/`：初始化、生产、恢复和检查规则；
- `07_项目模板/正式项目模板/`：正式项目的元数据、快照、规划、正文和检查报告结构；
- `08_原始资料/`：已登记的工作区原始资料；
- `05_正文/`、`06_测试验证/`、`docs/`：现有正文、测试验证和记录资料。

这些目录是 Cline 的内部实现结构。用户只需在聊天框发送包含“小说”的请求并按入口中的选择确认或调整，不需要手动操作上述路径。
