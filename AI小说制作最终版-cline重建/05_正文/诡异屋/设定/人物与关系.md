# 人物与关系

## 林砚（主角）

- 身份：档案修复师，负责清点和修复无人认领遗物。
- 表层目标：完成旧屋遗物清点，找出失踪房主的有效身份记录。
- 深层需求：确认自己的童年记忆是否可信，并摆脱被他人定义的过去。
- 能力：物证观察、纸张与记录修复、空间细节记忆。
- 限制：面对与童年火灾相关的气味和声音时会出现判断迟滞；缺乏现场执法权限。
- 误判：最初认为旧屋异常来自一个仍在屋内活动的单一凶手。

## 周既明

- 身份：旧城派出所警员，七年前失踪案的协查人员。
- 表层目标：阻止案件在拆迁前扩大为公共事件。
- 隐藏目标：保护当年被错误归档的证人。
- 资源：旧案卷宗、现场权限和当地关系网络。
- 与林砚关系：互相利用起步，经过三次信任变化后形成有限合作。

## 许棠

- 身份：旧屋原房主的女儿，现为拆迁项目法律顾问。
- 表层目标：尽快完成产权清理。
- 隐藏信息：她知道旧屋存在一套“替换门牌”的习惯，却不知道其真正用途。
- 功能：提供关系和产权线索，同时持续制造道德选择。

## 顾怀山

- 身份：已失踪的原房主，档案中被标记为离家出走。
- 故事功能：缺席者。通过遗物、录音和他人叙述影响当下行动。

## 关系变化计划

林砚与周既明：怀疑 -> 利用 -> 暂时信任 -> 因隐瞒决裂 -> 以有限事实重新合作。

林砚与许棠：求证 -> 对立 -> 发现共同代价 -> 保护与揭露之间的冲突。
