# 潮痕入骨 第CH01章

## CH01-S01

沈砚缓缓步入外门检测场，目光在值守弟子的记录本上停留片刻。他侧身挪步至一旁的检测石前，仔细查看那些旧痕，眉头微蹙。这时，陆昭缓步走来，站在不远处，目光警惕地盯着他。“第七息异常？”陆昭轻声询问，声音里藏着不易察觉的担忧，“是不是……修行出了问题？”沈砚收回目光，抬手按住检测石边缘，用力一推。检测石微微颤动，旧痕上的灵纹清晰。“不是修行不稳。”他回答得坚定而平静。陆昭侧头，似乎在衡量他的言辞。片刻后，他收回视线，侧身挪步至另一处，似有所思地环顾四周。沈砚默默观察着检测石的痕迹，在心中默念着第七息的位置与回亮时间。此时，一道微弱的光芒从镇潮阵的方向飘来，与检测石上的灵纹相呼应。“第七息的回亮……”陆昭轻声自语，“难道是……阵法？”
沈砚收回目光，抬手按住检测石边缘，用力一推。检测石微微颤动，旧痕上的灵纹清晰显现。他侧身挪步至另一处，手指轻轻抚过一道细纹，眉头微蹙。“第七息的回亮……”陆昭轻声自语，“难道是……阵法？”沈砚收回视线，抬手按住旁边的检测石边缘，用力一推，检测石再次微微颤动。他侧身挪步至另一处，手指轻轻抚过一道细纹，眉头微蹙。这时，一道微弱的光芒从镇潮阵的方向飘来，与检测石上的灵纹相呼应。“第七息回亮时，检测石的细纹与镇潮阵方向同时发白。”沈砚低声道，“难道是……阵法？”陆昭侧身，目光警惕地盯着他，轻声反问：“你确定不是修行不稳？”
