# 潮痕入骨 第CH01章

## CH01-S01

沈砚走进栖云宗外门检测场时，没有先看检测器，而是先看人。沈砚进入外门检测场，先观察值守弟子的记录顺序和检测石的旧痕。今日检测决定晋升资格，任何质疑都会被记为扰乱秩序。他把目光从人群里收回来，知道这一次若走错一步，失去的不会只是手里的合格牌。观察_识别_场景_机会在栖云宗外门检测场中改变了沈砚对线索的判断。
沈砚把手停在半寸之外，等那一点不合规的光自己暴露。第七息回亮时，检测石的细纹与镇潮阵方向同时发白。执律堂将异象归为修行不稳，要求他立刻离台。他没有急着给眼前的异样下结论，只把它同先前记住的细节放在一处，等着看哪一边先露出破绽。检测石的三道细纹每隔六息同时亮起，和先前两次偏差的间隔分毫不差。
他换了个不带指控的问题，把答案的路让给对方。沈砚用不带指控的问题追问检测记录的间隔，陆昭替他遮住旁人的视线。陆昭的药额依赖宗门考核，不愿被他的追查拖入禁令。沈砚把真正想问的话压在舌下，只留一个足够普通的问题。对方若答得太快，便是在替谁守门；若答得太慢，也一样。
沈砚没有争辩，只把能复核的细节记在掌心。他趁记录册翻页时记下被药灰填过的刻痕和第七息的偏差。若被发现私留读数，晋升资格会当场冻结。他没有回头。线索落进手里的一刻，代价也随之落下；从此以后，旁人替他承担的每一笔账都不能再假装与他无关。
旧域里的第二声回响穿过石墙，落在沈砚耳中。沈砚把异常读数藏进袖中，决定去档案廊寻找潮灾前的原始记录。他失去当场申诉的机会，只能在规则之外继续追查。沈砚把这件事记下，没有替它补出答案。它已经不再是可以搁置的疑心，而是逼着他往前走的一道门。

## CH01-S02

沈砚不问谁做的，只问这件事曾经发生过几次。他以缺失页码为由向许照微提问，不直接说出镇潮阵异常。许照微必须在守规与保留线索之间选择。他没有急着给眼前的异样下结论，只把它同先前记住的细节放在一处，等着看哪一边先露出破绽。嫉妒_重度在栖云宗藏卷阁档案廊中改变了沈砚对线索的判断。
他沿纸边摸过去，摸到的不是破损，而是有人刻意留下的整齐断口。许照微让他看见被整齐切走的一页，页边仍留有潮期编号。缺页只能证明删改存在，无法解释谁在删改。沈砚把真正想问的话压在舌下，只留一个足够普通的问题。对方若答得太快，便是在替谁守门；若答得太慢，也一样。
沈砚没有争辩，只把能复核的细节记在掌心。沈砚把页边刻痕与检测石读数并列记下，发现两者的时段重合。他不能留下会暴露许照微的抄录痕迹。他没有回头。线索落进手里的一刻，代价也随之落下；从此以后，旁人替他承担的每一笔账都不能再假装与他无关。
旧域里的第二声回响穿过石墙，落在沈砚耳中。许照微把缺页留给他，同时要求他不得提及自己的名字。下一轮检测即将开始，证据必须在被收回前找到用途。沈砚把这件事记下，没有替它补出答案。它已经不再是可以搁置的疑心，而是逼着他往前走的一道门。

## CH01-S03

夜色把栖云宗外门回廊与封存室外的禁线照得发白，沈砚在门前停了下来。沈砚带着缺页回到封存室外，禁线已把回廊灯火隔在身后。执律堂正在追查缺失读数，陆昭被叫去问话。他把目光从人群里收回来，知道这一次若走错一步，失去的不会只是手里的合格牌。决策_不可逆_后果在栖云宗外门回廊与封存室外中改变了沈砚对线索的判断。
他看着对方，没有用真相逼迫对方替自己选择。陆昭要求他交回证据保住药额，沈砚承认自己尚未掌握真相。两人的利益第一次正面冲突，任何承诺都无法消除风险。他没有急着给眼前的异样下结论，只把它同先前记住的细节放在一处，等着看哪一边先露出破绽。决策_代价_避免在栖云宗外门回廊与封存室外中改变了沈砚对线索的判断。
沈砚抬手叩门，按记下的节拍等最后一声回应。沈砚按缺页上的节拍叩门，第三次回声来自旧域更深处。这一步会留下触碰禁线的可追查痕迹。沈砚把真正想问的话压在舌下，只留一个足够普通的问题。对方若答得太快，便是在替谁守门；若答得太慢，也一样。
沈砚把那件象征退路的东西压向禁线。他没有交回异常读数，而是把可复核的刻痕与缺页一同藏起。陆昭因此被记为协助者，药额和晋升资格都可能受影响。他没有回头。线索落进手里的一刻，代价也随之落下；从此以后，旁人替他承担的每一笔账都不能再假装与他无关。
门锁合上的声音落下时，沈砚才明白线索并不是无偿递到手里。执律堂宣布暂缓沈砚的晋升资格，夜里的镇潮阵再次回响。退路变窄后，他必须决定是否继续进入旧域。沈砚把这件事记下，没有替它补出答案。它已经不再是可以搁置的疑心，而是逼着他往前走的一道门。
