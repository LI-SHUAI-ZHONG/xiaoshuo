# 潮痕入骨 第CH01章

## CH01-S01

晨光初破，照耀在栖云宗外门检测场的大门前。沈砚踏着青石铺就的小路，脚步轻缓而坚定地走向检测场内。今日的测试关系到他能否顺利晋升为正式弟子，心中虽无太多情绪，但也未免不紧张。大门两侧各有两名执律堂弟子值守，一人记录，另一人手持检测石，目光警惕地盯着每一位入场者。沈砚走到记录弟子面前，微微停顿，观察着他的笔迹和动作的流畅度。“今日测试如何？”他轻声问道，目光扫过检测石表面那条条旧痕，似乎在寻找什么不同寻常之处。值守弟子抬头回应：“一切正常。”他回答得简洁明了，但沈砚注意到他的眼神并未完全对上。紧接着，另一名执律堂弟子走过来，手中捧着一块检测石递给沈砚。“请进行测试。”沈砚接过检测石，感受到那微微温热的表面，心中暗自警惕。他按照要求将石块轻触于胸前，闭目凝神，仔细感受着体内第七息的流转。片刻后，检测石上亮起微弱的光芒，与镇潮阵中灵息回声同步闪烁。沈砚睁开眼，眉头微蹙：“这是怎么回事？”他的话语虽轻，却带着不容忽视的质疑意味。执律堂弟子不愿多言，只是淡淡回应：“修行不稳，需再观察。”沈砚并未放弃，再次询问道：“第七息为何会与阵法回声同步？”他的声音中隐隐透出一丝不易察觉的愤怒，但很快又恢复平静。执律堂弟子表情僵硬，似乎在权衡是否该继续隐瞒。他最终还是摇了摇头，“这不符合宗门规定，不得公开讨论。”言罢，转身向内走去，留下沈砚独自站在检测场门口，手中紧握着那块记录了异常的检测石。
