# 小说项目初始化

用户只需要提供四个值：主类型、可选题材组合、目标总字数和目标章节数。人物、书名、世界观、主线、谜团和章节内容在初始化时保持为空，不能由模板提前伪造。

```powershell
py -3 "D:\小说\脚本\初始化小说项目.py" `
  --output-root "D:\小说项目\玄幻悬疑" `
  --type "玄幻" `
  --themes "悬疑" `
  --target-words 300000 `
  --chapters 100
```

初始化器会生成：

- `配置/project_config.json`：只保存用户输入、目标规模和空白项目事实字段。
- `文档/证据/小说资料选择清单.json`：保存所选类型的核心元素、风格约束、类型组合资料、来源位置和共享叙事资料范围。

后续 `project_planning` 阶段必须只从该清单中的资料检索并生成项目蓝图。它生成的书名、人物、设定、卷纲和章节计划必须带来源记录与生成版本；未选择的类型资料不得混入项目事实或正文。
