# 潮痕入骨 第CH01章

## CH01-S01

沈砚抬手轻拂过身边的记录石，指尖划过处留下细密的温润痕迹。他侧身避开了值守弟子的目光，迅速翻阅着前几日的检查记录。陆昭在一旁紧绷着脸，不时侧头观察沈砚的动作。“第七息回亮，确实有迹可循。”沈砚低声自语，手指轻轻按住一处旧痕，“但这光华为何如此诡谲？”值守弟子轻咳一声，清了清嗓子：“沈师弟，今日检测严格，请莫要私下探查。”沈砚收回手，不动声色地挪步至另一侧检测石前。他侧耳倾听，试图捕捉周围细微的声音，但只听到一阵阵脚步声和轻微的呼吸。“第七息回亮与镇潮阵的灵息回声同步。”陆昭低声道，“你若查出异样，别让执律堂牵着鼻子走。”沈砚盯住石面上的一个微小变化，凝神细辨。他发现一处细纹似乎比其他地方更清晰，仿佛被刻意标示过。“第七息的异常或许来自阵法。”沈砚轻声回应，“但需更多证据才能质疑执律堂。”陆昭眉头紧锁，目光在两人之间来回游移，最终收回了警惕的眼神。

沈砚收回手，抬眸望向陆昭：“你是否察觉到第七息的细微变化？”陆昭皱眉，目光闪烁不定。沈砚侧身挪步至另一块检测石前，指尖轻触细纹，温润的手感似乎在与那道灵息对话。“第七息回亮时，镇潮阵也同步发白。”他低声说道。陆昭紧抿双唇，侧身避开沈砚的目光，抬手按住自己的药盒，仿佛在自言自语：“考核就在眼前，不能因小失大。”沈砚凝视着检测石上的细微变化，指尖轻轻划过旧痕，似乎想从中找到更多线索。“第七息的异常或许与阵法有关。”他轻声回应。远处，一道白光再次闪烁，与镇潮阵的方向同步发亮。沈砚侧身，抬眼望向出口方向，那道光芒仿佛在指引着什么。陆昭紧绷的脸色中闪过一丝不易察觉的松动，但他随即收回警惕的眼神，抬手轻拂过身旁记录石上的旧痕。
