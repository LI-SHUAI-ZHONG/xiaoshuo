# 潮痕入骨 第CH01章

## CH01-S01

沈砚走进栖云宗外门检测场时，没有先看检测器，而是先看人。沈砚进入外门检测场，先观察值守弟子的记录顺序和检测石的旧痕。今日检测决定晋升资格，任何质疑都会被记为扰乱秩序。他把目光从人群里收回来，知道这一次若走错一步，失去的不会只是手里的合格牌。
沈砚把手停在半寸之外，等那一点不合规的光自己暴露。第七息回亮时，检测石的细纹与镇潮阵方向同时发白。执律堂将异象归为修行不稳，要求他立刻离台。他没有急着给眼前的异样下结论，只把它同先前记住的细节放在一处，等着看哪一边先露出破绽。
他换了个不带指控的问题，把答案的路让给对方。沈砚用不带指控的问题追问检测记录的间隔，陆昭替他遮住旁人的视线。陆昭的药额依赖宗门考核，不愿被他的追查拖入禁令。沈砚把真正想问的话压在舌下，只留一个足够普通的问题。对方若答得太快，便是在替谁守门；若答得太慢，也一样。
沈砚没有争辩，只把能复核的细节记在掌心。他趁记录册翻页时记下被药灰填过的刻痕和第七息的偏差。若被发现私留读数，晋升资格会当场冻结。他没有回头。线索落进手里的一刻，代价也随之落下；从此以后，旁人替他承担的每一笔账都不能再假装与他无关。
旧域里的第二声回响穿过石墙，落在沈砚耳中。沈砚把异常读数藏进袖中，决定去档案廊寻找潮灾前的原始记录。他失去当场申诉的机会，只能在规则之外继续追查。沈砚把这件事记下，没有替它补出答案。它已经不再是可以搁置的疑心，而是逼着他往前走的一道门。
