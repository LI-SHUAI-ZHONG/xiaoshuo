# Studio、高级能力与内容分配

本文是产品交付约束，配合04的模块归属、05的数据/API和06的工作流使用。各页必须有真实集合、详情、合法编辑、版本与运行状态；不能只做展示面板。路由是新增目标，旧书签保留跳转或兼容。

## 1. 页面与操作闭环

桌面布局为左侧导航、中央工作区、可收起的右侧AI/资料/审稿栏；小屏折叠为分区切换。默认中文。项目上下文始终可见。快捷搜索/命令面板只调用服务端已授权的操作，不能执行任意脚本。

| 页面 / 推荐路由 | 必须可操作的功能 | 必须显示的依据与结果 | 实现步 |
|---|---|---|---|
| 首次使用、登录 `/setup`、`/login` | 本地Owner初始化、登录/退出、会话撤销、OIDC配置 | 配置缺项、到期、恢复；个人无需第二个审批人 | 25 |
| 首页 `/dashboard` | 最近作品、继续章节、审批、失败恢复、预算 | 实际项目/运行列表；空库有创建/导入入口 | 34 |
| 项目 `/projects`、`/projects/{id}` | 建书、改名、搜索、归档/恢复、项目设置 | 字数、接受章节、工作副本、风险和索引滞后；无假统计 | 26、31、34 |
| 思想 `/projects/{id}/ideas` | 原话、附件、批注、关联理论、转成Brief | 原文与整理稿、来源、采纳原因；AI只追加候选 | 29、31 |
| 类型与主题 `/projects/{id}/design` | 自定义六维、类型混合、强度/比例、适用卷章、主题/结局 | 世界/冲突/人物/结构/情绪/语言影响、融合风险 | 31 |
| 规划 `/projects/{id}/outline` | 卷章场景树、重排、多线故事、冲突矩阵、因果、伏笔 | 重排影响、情绪曲线、信息释放、开放结局例外 | 31、34 |
| 世界 `/projects/{id}/world` | 规则、科技/力量、文明、政治经济文化、组织、地理和历法编辑 | 强/软规则、来源、状态历史、地点与事件关联 | 32、34 |
| 人物 `/projects/{id}/characters` | 六维档案、声音、心理/欲望/创伤/信念、目标、关系、成长、可知信息 | 时变状态、关系方向、行为证据；不自动合并同名人 | 32、34 |

| 知识 `/projects/{id}/knowledge` | TXT/MD/PDF/DOCX/HTML/EPUB导入、图片OCR、音频转写；检索、标签/关系、转译/审核/发布 | 原文件、页段位置、提取质量、来源/许可、索引代次、调用历史 | 29、40 |

| 流程 `/projects/{id}/workflows` | 定义/版本、DAG编辑、条件/输入/发布、发起/暂停/恢复/取消/重试 | 输入、审批、预算、节点结果、补偿/死信、SSE重连；无需手输ID | 28、34 |

| 出版 `/projects/{id}/publishing` | 版次、封面、章节选择、TXT/MD/DOCX/EPUB/PDF/项目包、旧稿导入、改编 | 目录/排版预览、manifest、进度、错误/下载 | 39 |

## 2. 高级能力最低真实实现

| 能力 | 可操作链 | 不算完成 |
|---|---|---|
| 自动规划/协作 | 用户目标→Plan→依赖/权限/预算验证→Run→角色→汇总/人审；描述符可版本化新建，能力由证据更新 | 固定framework_smoke；只有角色名 |
| 文明/世界/人物模拟 | 假设/快照/期限→事件→规则/资源/因果→人物/政治/经济/科技/人口/文化影响→分支比较→采纳 | 固定加减值称科学预测；直接改Canon |
| 创作实验室 | 自主创意/新类型→小原型→候选对照→同rubric评估→新项目或失败归档 | 无界生书、固定成功 |
| 作者数字孪生 | 可解释偏好/风格/审美/决策特征、修改对分析、版本学习、纠正/撤回、受权写作使用 | 一次点击推断永久价值观；空库称已学会 |
| 自主进化 | 观察→诊断→假设→候选→固定样本对照→策略/人审→晋升→监控→回滚；覆盖知识/检索/Agent/Prompt/流程 | DryRun恒通过；批准后无安装 |
| 模块/工具生成 | 缺口→接口/依赖蓝图→代码/迁移/测试包→沙箱→diff审查→独立安装→回退 | eval/import进主进程；自动修改生产源码 |
| 研究网络 | 本地/受权URL/搜索/API→领域分工→证据快照→互证/反证→转译→更新失效 | 自动拥有付费库；编造引用 |
| 长篇连续性 | 层级摘要、事件因果、角色信息、伏笔、每章输入快照、失效/重检 | 大上下文等于百万字无错 |
| 跨媒介/IP | 受权IP→漫画面板、影视剧本/镜头、音频脚本、游戏任务/分支/对话/资产包；各有schema和导出 | 只有media_type；承诺一键完整商业电影/游戏 |
| 协作生态/信誉 | 私有成员目录/技能匹配、作品/任务/讨论、合作评价、贡献证据、申诉、学习路线 | 假公众社区、假交易、无证据评分 |

托管默认预算内推进草稿。真人批准、预授权低风险策略、双人审批是不同政策，不把Agent记为真人。政策在25定义，由所有执行器统一读取。

## 3. 实际适配器

以下是工程选择，非购买建议。模型名/参数/价格配置化；每个适配器需真实协议、错误/用量、取消/未知结果恢复与归档，类名或HTTP空壳不算实现。启用取决于用户可用服务，不假定账号/地区资格。

| 方向 | 最小交付实现 | 启用条件 |
|---|---|---|
| 云文本 | OpenAI Responses；独立OpenAI-compatible Chat Completions | 对应模型、密钥、端点、额度 |
| 本地文本/向量 | Ollama chat/embed；其他本地兼容端点profile | 本地服务/模型及能力/维度 |
| 云向量 | OpenAI embeddings | 维度/模型不与8维旧索引混用 |
| 图像生成/编辑 | OpenAI Images；ComfyUI配置工作流 | 媒体模型或本地工作流/权重 |
| 音频 | OpenAI speech/transcription；ElevenLabs音乐/音效；本地导入/播放/分轨拼接 | 服务及格式配置；不默认复制真人声线 |
| 视频 | Runway创建/查询/取消/归档；ComfyUI视频工作流 | 账号或本地GPU/工作流 |
| 3D | Meshy preview→refine/GLB归档；本地GLB/glTF导入/场景放置/查看 | 生成用账号；本地查看无需密钥 |
| 研究 | Brave Search HTTP + 受限HTTP取文 + 本地文件/手动URL | 搜索key可选，资料权限/网络 |
| 身份 | 本地身份 + OIDC授权码/PKCE/JWKS | 团队IdP；个人不依赖IdP |
| 结算 | 手工导入/对账 + Stripe Checkout/Connect | 外部账户、授权、可达webhook |
| 发布 | 本地版本导出 + 可配置HTTP Publisher上传/查询/撤回 | 目标协议/映射、凭据、具体发布批准；未指定网站不编造专用连接器 |

媒体共用预算/权限，但有独立异步任务契约。能力矩阵明确流式/取消/幂等支持；不支持时拒绝，不以伪成功降级。

ComfyUI须按其实际队列/历史/输出协议接入；共享实例的全局interrupt不得误停其他人的任务，需独占执行租约或明确不支持按Job取消。[ComfyUI服务协议](https://docs.comfy.org/development/comfyui-server/comms_routes)。Brave用正式搜索接口获取候选URL，随后受限下载和证据定位；搜索摘要本身不能当全文已核验。[Brave Web Search](https://api-dashboard.search.brave.com/app/documentation/web-search/get-started)。

协议依据：[Responses流](https://developers.openai.com/api/docs/guides/streaming-responses)、[结构输出](https://developers.openai.com/api/docs/guides/structured-outputs)、[图像](https://developers.openai.com/api/docs/guides/image-generation)、[语音](https://developers.openai.com/api/docs/guides/text-to-speech)、[转写](https://developers.openai.com/api/docs/guides/speech-to-text)；[Ollama chat](https://docs.ollama.com/api/chat)、[embed](https://docs.ollama.com/api/embed)；[Runway](https://docs.dev.runwayml.com/api/)、[Meshy](https://docs.meshy.ai/en/api/text-to-3d)；[音乐](https://elevenlabs.io/docs/api-reference/music/compose)、[音效](https://elevenlabs.io/docs/api-reference/text-to-sound-effects/convert)。核对日期2026-09-24；施工时再核对选用SDK，不猜未描述字段。

## 4. 内容分配

| 内容 | 初始状态 | 入口/归属 |
|---|---|---|
| 原思想/聊天/知识资料 | 保留原文件，不自动导入正式库 | 作者选择→思想/知识导入，保留来源 |
| 作品/世界/人物/风格样本/读者反馈 | 正式库为空 | 手工、导入或作者发起生成，不灌示例书 |
| 类型范例/专属理论/专有rubric | 可以为空 | 类型/组件编辑器或内容包 |
| 市场商品/订单/收益/成员 | 可以为空 | 明确创建/邀请/导入/真实交易 |
| 通用Prompt/工作流/schema/校验器/权限 | 必须有可执行版本 | 软件发布包，清单见11 |
| 类型六维/场景/人物/世界/转译空模板 | 必须有表单和校验 | 软件schema，不预填作者理论 |
| 质量通用维度/尺度/缺证据规则 | 必须有 | 结构/因果/人物/叙事/语言/读者体验；可调整，不固定高分 |
| 密钥/模型/价格/GPU/端点 | 待用户配置或受权本地配置 | Settings；缺项显示missing/unknown |
| 测试数据/模拟响应 | 仅测试目录和45隔离库 | 不进入正式库或真实学习证据 |

## 5. 开放API

25实现可撤销/到期/最小scope的个人访问令牌，创建时仅返回一次；服务令牌不能伪造真人审批。39/42实现授权Webhook订阅、HMAC签名、重放窗口、重试/死信，不带未授权正文。OpenAPI、客户端、错误码/分页/额度/SSE说明随43交付。插件仍经ToolGrant，不能获取整库访问权。
