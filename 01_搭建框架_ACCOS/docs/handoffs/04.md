## 本阶段变更

### Kernel

- `kernel/settings.py`：必需、可选和功能开关三组配置；代码默认值、`.env`、进程环境变量优先级；生产弱凭据拒绝；安全摘要。
- `kernel/ids.py`：UUIDv4 选择、规范序列化和请求/任务/Trace 关联 ID。
- `kernel/clock.py`：可替换 Clock port、系统 UTC 时钟与 RFC 3339 `Z` 序列化。
- `kernel/contracts.py`：语义版本、offset 分页边界和幂等键。
- `kernel/result.py`：显式 `Success`/`Failure` 结果联合类型。
- `kernel/errors.py`：配置、请求、非法状态、依赖与未知错误码，以及不暴露实现细节的错误信封。
- `kernel/logging.py`：单行 JSON、上下文关联 ID 和递归敏感字段/URL user-info 脱敏。
- `kernel/health.py`：liveness、关键依赖 readiness、超时与异常隔离；可选项不阻塞 readiness。
- `kernel/lifecycle.py`：模块注册协议、唯一名称、顺序启动、逆序关闭和部分启动回滚。

### Adapters 与 composition

- `adapters/health.py`：PostgreSQL `SELECT 1`、Redis `PING`、S3 bucket 可达性和 AI Provider 静态状态探针；异常文本不穿透健康契约。
- `composition/root.py`：唯一实例化具体探针的位置；API 与 Worker 均调用 `build_container()`。
- 当前只注册 `kernel` 与 `health` 两个生命周期模块。
- 自定义架构检查新增 kernel/domain 对 FastAPI、Uvicorn、Starlette、psycopg、Redis、MinIO、SQLAlchemy 等框架与 SDK 的禁止依赖。

### API 与 Worker

- `python -m accos.entrypoints.api`：加载共享设置、输出脱敏启动事件并运行 Uvicorn。
- `GET /live`：只报告进程存活，固定 HTTP 200。
- `GET /ready`：关键依赖全健康时 200；任一关键依赖不可用时 503；Fake AI 为 `not_configured` 且不阻塞。
- HTTP 中间件：关联 ID 传播、单一请求完成日志、安全响应头和未知异常安全映射。
- `python -m accos.entrypoints.worker`：加载同一容器，登记空 TaskRegistry，等待 SIGINT/SIGTERM/SIGBREAK 并执行逆序关闭。
- `.vscode/launch.json`、`.vscode/tasks.json`：API/Worker 占位入口已替换为真实模块入口。
- `docs/runbooks/backend-runtime.md`：启动、停止、健康、关联 ID、配置、日志与排障说明。

### 工具链维护

## 健康与错误契约摘要

- `GET /live`：永远不探测外部依赖；存活时 200。
- `GET /ready`：200 `ready` 或 503 `not_ready`；`checks` 项只含 name/status/critical/detail。
- 错误信封：`error.code/message/correlation_id/trace_id/details`。
- 关联头：`X-Correlation-ID`、`X-Request-ID`、`X-Trace-ID`、可选 `X-Task-ID`。
- 标识符：规范小写 UUIDv4；时间：UTC RFC 3339 `Z`。
