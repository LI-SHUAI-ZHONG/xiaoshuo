## models.v2调用与Provider

- `ModelInvocation`使用受权`ContentRef`和内容型消息，实际输入、局部输出和最终输出保存为项目内不可变资产；日志、Outbox和列表响应只含状态、哈希、计数与引用。
- OpenAI Responses支持文本、strict JSON schema、工具、流式事件、refusal/incomplete、用量和供应商续接信息；OpenAI embedding使用`/embeddings`并校验顺序、维度与有限浮点数。
- Chat Completions-compatible和Ollama保持独立协议适配；Ollama使用`/api/chat`与`/api/embed`，不把Responses或Chat的能力默认套到本地模型。
- 正常模式仅在`ACCOS_MODEL_MODE=real`且`ACCOS_REAL_PROVIDER_CALLS_ENABLED=true`时允许发起调用。`test/demo`才注册Fake旧契约；正常模式未配置时返回`CONFIG_REQUIRED`，不以Fake伪装真实输出。

Provider能力不是按协议暗示，而是由每个版本化`ProviderProfile.capabilities`显式声明：

| 协议 | 实现入口 | 可声明能力 | 端点/限制 |
|---|---|---|---|
| `openai_responses` | `OpenAIResponsesProvider` | text / structured / tools / stream / embedding | `/responses`与`/embeddings`，云端密钥只由`secret_ref`解析 |
| `chat_completions` | `ChatCompletionsProvider` | text / structured / tools / stream / embedding | `/chat/completions`与`/embeddings`，参数名按profile冻结 |
| `ollama` | `OllamaProvider` | text / structured / tools / stream / embedding | `/api/chat`与`/api/embed`，本地URL必须进入安装级allowlist |

`secret_ref`必须引用当前工作区的活跃密密记录，Provider profile、API、交接和输出均不回传明文凭据。本地profile的endpoint禁止内嵌凭据。

## Prompt、Agent与工具循环

- 包内通用Prompt为`agent.task`、`director.intent`、`director.clarify`、`director.route`、`director.plan`、`director.replan`和`director.meeting_summary`。每个文件含正文、必需变量、任务种类和受限输出schema；manifest的SHA-256/长度已静态复核。
- 自定义Prompt按`id/version/checksum`不可变发布，写入需要`If-Match`并在执行前冻结Prompt和Provider版本。变量与输出均做schema校验。
- `RealAgentExecutor`把任务/上下文渲染为Prompt，通过models.v2执行，用`call_id`关联工具请求与结果，且同时受Agent调用次数、Token上限和工具循环上限约束。
- Agent任务写入持久队列；工作者租约过期可恢复。结果先落受控候选内容资产，不直接改写第26步正文head。Planner结果与普通角色结果保持独立任务种类和schema。

## 流、预算、路由和历史

- `model_call_events`按调用序列持久化，SSE支持`Last-Event-ID`恢复。断流时暂存`partial_ref`；只有完整输出不可变落盘后才进入`completed`。`refused`、`incomplete`、`cancelled`、`failed`和`unknown`保持分态。
- 每次初试、重试和fallback分别用PostgreSQL原子预留预算；结算保存价格版本、Token和微美元费用。无法确认是否计费时保持`unknown`占用，仅能用受权证据ref人工对账，不把未知价格当作0。
- Redis令牌配额在worker之间共享；路由先校验能力、参数、上下文与隐私约束。含供应商续接信息的重试锁定原Provider版本。
- Studio已提供模型/Provider/预算设置、Prompt发布与预览、项目调用历史/并排比较/详情/取消/对账/人工评分，以及真实Agent任务入口。

`models.call-settled`事件仅记录调用ID、终态、用量、费用和内容引用，不携带输入/输出正文。
