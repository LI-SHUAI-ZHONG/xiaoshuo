1. 运行 `uv run pre-commit uninstall` 移除本阶段安装的 Git 钩子。
2. 删除本交接“本阶段变更”列出的阶段 02 文件，并将 `README.md` 恢复到执行 01 内容；保留执行 01 的 `.gitkeep`、ADR、架构文档和整个 `执行/`。
