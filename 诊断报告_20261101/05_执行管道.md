## 从入口到证据的实际控制流

CLI → run_pipeline → 生命周期验证（CLI强制）→ set_project_root / initialize_run → main → 执行边界 → 输入快照 → 灵感选型 → 资源注册 → 启动绑定合同 → 解释词注册与创作绑定 → 既有授权重建/审计/投影同步 → 配置校验 → 激活矩阵 → 来源能力审计 → 运行准入刷新 → 模块循环 → 运行清单复核/失败回执。证据：同文件:3580–3888。

模块输出经字典合并进入共享 context（:3685）；同名字段可被后续模块覆盖，审阅时应优先使用带 module_id 的文件而非最后 context 推断历史状态。上游失败后除交接模块外跳过（:3662–3675），所以最终存在交接报告不等于前面全部执行。模块内部只对 status=failed 或 self_check.passed=False判失败（:3679）；发布状态还由专门门判断。

`--project-root`必需，`--project-id`、`--genres`、`--run-id`可选；命令行身份与已配身份不一致会失败（:3643–3646、3880–3888）。`run_pipeline(enforce_lifecycle=False)`为函数默认，CLI显式传True；不得以直接导入函数替代正式入口并称生命周期已检查（:3838–3860）。所有脚本CLI参数的真实默认/必需/choices见05C。

## 资料绑定、授权、消费：不能混为一谈

注册记录路径、哈希、解析状态和质量；草稿可用与正式事实可用分别计算（`03_运行资料/脚本/资料注册与完整性.py:110–194`）。启动绑定合同要求资料库、类型系统、类型连接、静态网络、动态网络、锚点网络的资源键存在、registry passed、project_id存在；它不能证明所有条目都已写进正文（管道:1348–1395）。

main调用绑定生成后，比对来源数量，重建的是已有显式授权并同步审计投影（:3615–3629）。模块08之后用 scene_contexts 和 frozen_bindings 构建运行资料包，要求行动节点有 binding_id；正文后再次对 run_id/package_id/continuity_hash/位置和可观察结果验证（:3686–3768）。模块10/11分别检查 editorial/delivery阶段资料包（:3769–3779）。这些是静态证据契约；本次没有运行以验证具体授权是否满足。

消费日志生成器会把场景字段组合成 purpose/condition/decision_statement，并写 consumed 状态（:1573–1659）；因此“日志标 consumed”弱于“正文中有独立可核验变化”。更强的运行来源校验在:273–326，显式段落绑定在:2701–2727、2819以后。不要使用授权JSONL行数代替创作利用率。

## 提示词与模板泄漏

05E保存当前剩余提示词构造函数的**完整源码**，每段引用不超过380字符，按顺序拼接即还原。模板字段为场景、地点、目标、阻碍、动作、压力、前置结果、项目冲突、来源方法和上一段；截断由max_chars参数控制（管道:1335–1345）。不存在已核实的当前system prompt、模型名、temperature、采样参数、重试或服务地址；不能补写一个想象的模型调用。

标签进入的风险点：`来源方法`可直接含条目名/id（:1342）；默认锚点证据是拼接“改变了…判断”（:2764–2767）；来源translation_evidence结果可以取场景状态/钩子（:2915），不应单凭它证明文学落实。清理器按字符串/正则删除绑定主线、动作留下结果、空间光线套话等（:1421–1434）；是后验过滤，可能改变作者原句，也不能保证移除所有内部语义。元话语与锚点名泄漏另在:3259–3282检查。

## 复用与舍弃建议

可优先保留：初始化输入契约、项目隔离、来源路径/哈希、明确binding、运行资料包、失败回执和发布状态分离（初始化:88–202；管道:273–326、3686–3834）。需要重构：巨大共享context、动态规则调度与副作用写入耦合、宽泛异常捕获、以关键词计数代文学质量（上述行号）。历史 `.before_*` 仅作版本比较；测试保留回归价值；一次性搬运、融合、修复、重建脚本先隔离并做幂等/输入输出审查，不进入新创作主路径。05A对每个文件提供分类与处置建议；分类是静态名称/职责启发式，不是可直接删除清单。

未核实：当前机器依赖版本、可用模型、任一历史run完整性、命令成功率、真实全链运行耗时和文学产出质量。语法通过不代表主流程可用；本报告指出的作用域错误仍待授权修复后用隔离项目回归。
