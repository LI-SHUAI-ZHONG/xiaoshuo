- `novel start/show/resume/cancel` 保存托管分支、Brief、场景顺序、预算、模型配置和各步尝试。设计任务从 Brief 进入书级方向确认，再生成近期可写方案。已应用的父方案可用于直接细化。写作、修订和续写使用 M8 批准的场景及卡片。
- 写手在前场独立事实审查通过后读取同批候选变化。人物所知按故事时间查询，读者信息按披露顺序查询。前场证据和候选投影都固定版本。核心目标、世界规则、重要生死、视角或终局承诺变化会等待作者决定。审稿要求修订时最多两轮，达到上限后可由作者决定是否保留当前稿，再进入事实检查。
- 作者确认的草稿、变化单及冻结清单绑定同一接受批次。接受指针、事件、分支版本和任务完成检查点在一个 SQLite 事务提交。退回前场时记录拒绝决定，标记依赖它的后场候选为过期。候选正文留在尝试记录中供检查。
- 同一任务用跨进程锁占用。重试保留原消息、配置、结果与费用预留，并用新尝试 ID 发请求。额度不足时可按原范围提高上限后恢复。Brief、分支、大纲或方法版本变化时，任务提示过期并保留旧产物。取消后停止后续请求，已发请求的返回仍入记录。
