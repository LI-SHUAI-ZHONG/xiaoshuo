# 生产任务与资料需求规格 v1

本规格在审计结果上规定资料库要服务什么。**现有核心步骤的前置不能被方法条目取消。** 方法自己的前置与核心前置应取并集，并在未来项目调度中绑定实际产物及版本；本轮只实施方法结构/审核/查询，没有实施这些项目就绪检查。

## 资料与产物的四种身份

1. 六大原始资料及静/动网络：原文与缺义照实保留，现用来源资格、保护文件和裁定不因方法库新增而改变。
2. 参考作品观察：明确作品版本、卷章场/字符范围和真实原文，区分观察与解释。位置匹配只能证明引用真实，不能证明解释正确或跨章作用成立。
3. 可复用方法：从作品和制作需求中归纳，填写八类要求、适用边界和反例。方法不是原文条款，不因批准就自动成为本书事实。
4. 本项目实例：未来将方法应用到当前人物、关系、事件、章场及状态，形成真实项目卡和后续执行任务。它需自己的批准与版本，不能照搬来源书情节。

## 每次调用必须回答的问题

| 问题 | 方法库已经保存/检查 | 项目调用阶段还须检查 |
| --- | --- | --- |
| 为何现在采用 | 生产任务、适用条件、层级、类型范围、不适用情况 | 当前 Brief、父纲、已接受状态与本步目标是否匹配；冲突须明确处理 |
| 前置是什么 | 前置标识、来源种类、具体资料名及满足要求；操作引用这些前置 | 实际产物 ID/字段/版本/哈希、批准状态、当前分支；不能只给一个同名文本 |
| 怎样做 | 有序操作、每项输入与输出标识 | 模型是否按操作实例化、有没有偷换前步结果；缺必需前置返回补设计 |
| 形成什么 | 真实阶段字段与允许卡种、预期内容 | 生成本书世界/人物/剧情/卷章场/伏笔卡和条件产品；对应约束是否保留 |
| 给谁用 | 每个输出的指定下游和执行职责 | 下游是否收到对应版本并提交执行回执；不是引用 ID 出现就算使用 |
| 如何验收 | 每个输出的检查及所需证据 | 设计—正文—审稿是否一致，是否有实际文本位置、状态证据与作者评价 |
| 根据什么 | 来源作品、短摘录、字符范围、冻结源哈希和解释 | 多处证据是否支持所说的结构/因果/弧光；样本是否完整、是否存在反证 |

方法查询没有把自由文本条件自动判为满足。对条件的机器结构核对、模型分析和作者裁定必须分别记录，不能以字段非空冒充意义通过。

## 关键生产任务的细度要求

以下是后续拆解与项目实例化应交付的内容，不是本轮已生成的类型写法，也不是对所有作品统一施加的定额。

| 任务 | 原作中要辨认的内容 | 本项目应形成的具体设计 | 必须追到的消费者与证据 |
| --- | --- | --- | --- |
| 全书主线 | 总问题、读者承诺、主角欲望/阻力、关键选择、代价、不可逆转折、结局兑现及因果关系 | 选择后的全书方向、主要节点及各段承担的职责；候选方向不能同时冒充已批准主线 | 分卷/章纲对上层节点的覆盖；结尾如何兑现开端；不只是一段梗概 |
| 分卷与连续章纲 | 每卷目标/转向；每章目标、冲突、选择、结果与下一章回应 | 上层版本、范围、进入状态、事件序列、章末交接、未决问题与已确定安排 | 相邻范围回应关系、事件前后条件、最终全书覆盖；已写章与计划章状态分开 |
| 人物及弧光 | 独立目标、行为/能力边界、信念与关系初态、压力、选择、代价、实际变化 | 人物卡、变化条件和关联事件；每次转变依据已接受状态或明确候选 | 行动/场景/状态设计以及声线与知情审查；不能把性格标签当变化链 |
| 支线与关系 | 支线独立目标、关系成立条件、交汇事件、冲突与选择造成的关系后果 | 实体端点、成立/变化条件、主支线相互影响及允许传播范围 | 事件、行动与状态传播；未确认的影响仍为候选 |
| 事件与行动 | 触发、前驱、参与者、资源/能力限制、阻碍、应对、代价、结果、失败门 | 实际事件候选及完整动作步骤；缺条件的候选进入等待 | 场景必须选择有依据的事件/行动；正文和状态证据不得倒果为因 |
| 场景职责 | 视角、进入状态、人物各自目标、冲突、信息权限、选择和结果 | 场景卡、每位人物职责、允许披露、选定事件/动作、计划结果 | 锚点、表达、写作、审稿与状态提取核对同一设计版本 |
| 钩子与问题接力 | 如何引起期待；当前兑现了什么；何处回应/升级/终结；是否只有风险或悬而无解 | 同一问题标识、产生/回应事件、当前结果、下一步任务、读者与 POV 各自所知 | 剧情→事件→场景→表达及续章交接；短程钩子不能冒充长期伏笔安排 |
| 伏笔与承诺 | 埋设、提示、休眠、误读、揭示和回收的多处位置；意义是否先后相符 | 实际伏笔卡、已埋位置、计划提示/回收事件、窗口及例外依据 | 当前范围的具体任务、跨章记录和已接受正文；统计采用范围完整时才计算 |
| 节奏与情绪 | 事件/章场顺序、信息密度、紧张与释放、情绪前后值及触发、转换作用 | 绑定真实事件的信息/情绪序列、场景职责与呈现节拍；说明节奏改变的目的 | 表达和按范围审稿；章场缺失时标待核，不能用局部估全书或强行统一波形 |
| 世界与表达 | 规则限制如何约束选择；视角、对话、感知、动作和文风怎样承担叙事作用 | 世界规则卡及限制；按实际人物和场景的锚点/表达指导 | 人物能力、行动成本、允许披露及可观察表现；风格名不是具体执行设计 |

数量、比例、窗口只在相应原资料或作者项目安排明确采用时生效。原文残缺的十五节点/伏笔特征等继续标缺，不能把外部补充或模型猜测冒称原件。

## 已有但未接入、字段粗、缺义、待验证的标记

| 标记 | 处理方式 | 当前实例 |
| --- | --- | --- |
| 已有但未接入 | 复用真实对象，补明确方法/实例/消费者引用，不重建一套同名卡 | 新方法尚未接入项目调度与 `_uses/_receipts`；旧原资料已有独立交接能力 |
| 字段过粗 | 增加有关系的结构，不能只增一段自由文本 | 旧 slot/usage_text 迁为待补齐草稿；新方法已有输入/操作/产物/下游/检查标识 |
| 资料缺义 | 原文、解释和新增知识分开登记；未确认的不作原文要求 | 结构 41.2 的十五节点、伏笔 45.1 的特征清单等仍需原义核对 |
| 尚未验证 | 保留证据等级与待验收项，不以测试或批准数量宣布质量通过 | 完整作品结构、多章因果、方法适用性、真实负载、文学效果与作者评价 |
