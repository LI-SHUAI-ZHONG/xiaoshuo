# 两段小说提出的 25 项制作方法

2026-11-21 核验。红松宗片段让读者看完一次办理，再看下一人改选；临海一中片段让读者循正在发生的活动、学生的目光和教练的目光，逐渐注意到队尾少年。下表沿用原分析的顺序。两段用于界定需求，正式参考作品由用户后续导入。

章纲可为事件指定写法，场卡根据已选事件、行动和人物决定如何呈现。参考库有已批准的同类型实例时，场卡可选用适合本场的实例，也可说明与本场不合的地方。采用后，表达设计把该版本的一条操作交给本场具体的一拍。正文写本书的场面，审稿定位本稿原句。派生事件改变了本场用途时，场卡可以引用新事件的具体需求，说明原安排为什么推迟。每个事件可选一种连续段落安排，也可叠加多种单项写法。

| 序号 | 写法 | 复查前的基础与缺口 | 现在由哪一步落实、怎样核对 |
|---|---|---|---|
| 1 | 先给读者足够的时间地点 | 场卡有地点，重复或省略哪些信息缺少读者依据 | 场卡记录所在场地；沿用读者已知的内容须能追到可用前文，表达拍只补本次定位所需内容。 |
| 2 | 让焦点到来之前的世界已经运转 | 群体活动原本附在转焦写法内 | 章纲可独立要求已有活动，场卡指出入场时已经在做什么。只给门牌、场地或未来打算不能交差。 |
| 3 | 由等候进入真正的启动 | 有事件和参与者，条件与启动易混 | 场卡分出先已具备的条件、谁发出信号、谁第一个响应；审稿按实际先后定位。 |
| 4 | 让相对位置促成行动 | 有空间构图，位置和下个动作可各写各的 | 场卡把方向连到看、走、点名或递物，表达和审稿分别找出方位及由此发生的动作。 |
| 5 | 用感官证据建立现场 | 有感官描写资料，抽象评价也可能过关 | 为想让读者感到的东西选一项当场可感知的证据。集成测试中“很安静”的首稿被退修，修稿中能听见桌边灯芯细响。 |
| 6 | 使熟悉经验引出新理解 | 有设定披露，读者和角色的改观容易混在一起 | 表达拍给出熟悉情境、例外细节和读者所懂的变化；审稿只要求原句支持这次改判。 |
| 7 | 由陈设和活动说明场所用途 | 环境和活动已有各自字段 | 场内陈设或设施的缺席，与此处真实活动配对。原作先写递票、隔段才写验票闸，也能从同一具体事件取证。审稿核对读者如何从两者看出用途。 |
| 8 | 制度到生效时再讲清 | 世界规则和约束已存在，承诺前是否听见条款缺少检查 | 场卡绑定本项目规则、经办者及受约束者，核对触发、告知、决定的次序和知情范围。 |
| 9 | 按需要分次透露身份 | 有身份和初次出场设计，易把人物卡内容一次写尽 | 根据场景采用公开称谓、外貌、具体行动或已批准揭晓的身份；私有底稿留给设计与审稿。 |
| 10 | 借他人反应展示地位 | 人物卡可写身份，缺少当场可见的作用 | 人物专项把职权依据、本人举动和他人的应答或服从连在一起。可以先写反应，再写引起反应的人。 |
| 11 | 让对白完成一件当场的事 | 有对白方式，发话、听见、回应未必相连 | 表达设计分别指定说者、听者、目的及回答或行动；尚未答复可以停在发话，不能提前记为应允。 |
| 12 | 由职业经验产生具体语言 | 有人物声音，光填身份标签也可能被当作职业依据 | 从人物真实职责、经验和用词中取依据，把现场观察落实为具体台词。发出“重来”和对方做成分开取证。 |
| 13 | 关键动作写到使它成立的一步 | 有行动子步骤，容易只写意图或开始 | 选项目行动的具体步骤和执行者，给出动作及完成标志。审稿核对两处稿句是否真的写到了结果。 |
| 14 | 让物件连接两步 | 有道具和状态，取得凭证和兑付容易混记 | 场卡说明谁交给谁、实际收到什么；稿件里的交付和未来才可领的物品分别定位，续章各按其状态承接。 |
| 15 | 先示范，后分岔 | 已有连续段落拆解和写审，章纲不能直接指定 | 章纲可指明这一事件须有示范和改选；场卡、表达用两个人面对同一关口时不同的实际选择核对。 |
| 16 | 跨过重复过程，在变化处放慢 | 概述和省略能用在办理流程中 | 场卡可单选详略转换。表达指定先前的速度、恢复展开的拍及理由，审稿核对前后原文。概述所据为约数时保留其精度，同段有独立依据的其他数字仍能使用。 |
| 17 | 让上个细节带读者转焦 | 已有转焦写法，章纲不能直接指定 | 章纲可要求整组推进，表达拍须引用上一拍实际出现过的声音、动作、物件或目光，读者才能跟到下一个焦点。 |
| 18 | 分清转地点、转对象和进入内心 | 有叙述者与视角校验，转焦后容易越权 | 表达设计标明切换的性质、前后焦点和知情人；换到另一处可直接写新场地，观察到某人仍须守住其内心边界。 |
| 19 | 为这一段选择旁白或现场展开 | 有叙述模式，单段无法作为这种写法独立拆用 | 单拍可选概述稳定背景，或展开正在作的决定、判断、发现。核对实际表达模式、时序、归属和稿句，无须制造前后的切速。 |
| 20 | 分清确证、估计和可能收益 | 有推测类别，限定语和无名判断者易在下游丢失 | 引用观察依据和保留确定程度的措辞，判断者可保持未明。隔离试跑把“兴许”写成“肯定”后退修，邻近的独立事实仍能单独成立。 |
| 21 | 让解释留在解释者名下 | 有个人记忆和判断，容易误记到被解释者的动机里 | 分开设计当事人可见的选择和旁人的解释；要将动机登记给当事人，须另有当事人自己的证据。 |
| 22 | 读者的理解变化也可推进一章 | 有章场进展，状态补丁还可能强迫角色一起变化 | 场卡允许读者认识改变、角色和世界维持原状；写审核对读者为何改观，续章分别读取读者所得与现场变化。 |
| 23 | 用断段或连读控制停顿 | 有节奏资料，原稿是否真的换行缺少验证 | 表达指定相邻两拍是断开还是连读，并说明理由；审稿拿前后短引检查正文原有的自然段。 |
| 24 | 分清办毕、可办和待揭示 | 能交接结果，可能把本段之后的事提前登记 | 在接受稿件上分别保留已办、取得条件、待解问题及其原句。续章按版本承接具体事项，前稿失效后需重新核验。 |
| 25 | 判断一句是否值得占篇幅 | 有段落功能，缺少可执行的保留和删除两条路径 | 可保留原句并说明删后损失，也可指定删去重复或题外文字，定位仍成立的现场句、检查删改范围。章题、面向读者的互动单独标注。 |

### 怎样复验

- 参考拆解与调取可查 `src/nw/passage_catalog.py`、`src/nw/studio/corpus_passages.py`、`src/nw/production_methods/passage_sources.py`。客户端沿用第五版十二个分析方面，在叙述方面内选择具体方法；单句可证明的观察和必须以多处原文证明的连续过程分别验收。
- 章场交接可查 `src/nw/materials/passage_craft.py` 以及同目录的 `situated_passage.py`、`passage_people.py`、`passage_effects.py`、`passage_sequence.py`。现行做法按事件和场景选用，适合一拍的效果可以独立使用。
- 正文、审稿与续章定位可查 `tests/test_passage_craft_chain.py`、`tests/test_passage_people.py`、`tests/test_passage_effects.py`、`tests/test_situated_passage.py` 和 `tests/test_passage_prose.py`。隔离测试使用可控模型输出，让遗漏、错认和错误的段界实际触发退修，也验证清洁稿能够通过。

正式参考库导入和真实模型连续章稿的文学验收仍待进行。上述规则能检查采用了什么、稿句落在哪里、哪些结论有依据。读者是否真能顺着视线发现少年、听出台词属于谁、在段尾愿意接着读，需由实际阅读评价。

2026-11-22 补验了新安装和旧任务续跑。从 Git 交付包恢复到空目录后，22,941 条制作资料可读，恢复库的 155,455 个位置与 23,011 份裁定逐行核对均与正式库一致。Chrome 实测了单项写法、正文引文的选择、保存和重开；已有任务按各自冻结时的拆解要求续跑。在客户端的「预存库 → 现行拆解条目 → 叙述时序、视角与呈现」可以看到这 25 种写法。
