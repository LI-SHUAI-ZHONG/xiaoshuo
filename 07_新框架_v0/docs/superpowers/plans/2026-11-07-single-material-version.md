# 唯一现行资料版本实施计划

> 执行方式：superpowers:executing-plans；在当前授权任务内实施，不提交或推送。

**Goal:** 按用户要求只使用搭建现行最完整的一套六大资料，其他版本退出运行。

**Architecture:** 统一资料只读入口按确切来源ID/文件哈希限定当前六文件；旧数据及原件保留但不进入运行视图。按新作用域重建资格与发现索引。原16记录是本套内的条目，不是16个版本，不删除这些有效资料。

**Tech Stack:** Python标准库、SQLite、pytest，Windows PowerShell。

**Spec:** 本轮用户“只选最全的那个来源……搭建那个最新版……其他来源全部去除”。已逐文件核对：02_原版资料/原始资料、小说/原始资料及运行层精准融合完成版-20260819-03的六份文件SHA256逐一相同。采用02的现行路径作为唯一运行入口。

## Global Constraints

- 不运行真实模型；不改小说创作顺序、原文或正式正文；不删除或移动文件。
- 保留本套的原文、运行层、转译层及类型连接内治理规则；其他历史/派生/旧执行合同不供运行使用。
- 缺选择配置、确切版本改变或六类不齐全要报错，不能恢复为所有来源可读。
- 旧报告保留；新的“六文件”统计不等于全部条目含义已核或全文创作效果已通过。

## Review Focus

1. 只在列表过滤而原文ID仍可直接读：统一原文/子项入口必须同样排除。
2. 历史版本重复编号及相同哈希副本：以确切版本ID/路径和哈希选择，不按名字或哈希自动全放行。
3. 丢失/改动选择文件：登记标记使其不能静默回退到多版本。
4. 原文里的运行层/转译层及治理依赖：同一六文件内内容保留，不能当成其他版本删除。
5. 旧资格/发现索引：选定范围改变后必须重建并实际装载，不能沿用范围外条目。
