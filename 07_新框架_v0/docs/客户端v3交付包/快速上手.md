# 小说生产客户端 v3 · 快速上手

当前入口：[打开客户端](http://127.0.0.1:8767/)。重新启动可双击 `D:\搭建\07_新框架_v0\启动写作客户端.bat`；检测到已运行的客户端时会直接打开页面。

## 开始一本小说

1. 打开「设置 → 通用 API」，填写 OpenAI 兼容服务的基础地址、实际模型名称和保存密钥的环境变量名。地址和模型目前留空，密钥变量默认名为 `NW_API_KEY`。保存只表示配置已保存，真实连接仍待验证。
2. 首页点击「新建小说」，依次选择类型、风格、文笔、写法、世界观、人物、结构篇幅和卖点，再填写故事构想。推荐没有真实拆解数据时显示空位。
3. 点击「开始制作」进入制作台。左侧显示真实进度，出现待确认事项时，核对方案、填写决定理由并确认。
4. 全书设计完成后点击「继续制作」推进章节设计；随后继续写作、审稿和状态检查，作者确认后接受正文。

没有可用模型时会保留立项信息并报告阻断，不会生成占位小说。

## 设定篇幅并核对进度

立项第 7 步「结构篇幅」可填写全书目标、计划卷数与章数、每章及每场参考字数。只填全书目标也会在开始制作前显示。章场参考值可以留空，AI 会根据已批准书纲、本章冲突、人物选择及待兑现事项提出分配。批准章纲和场景卡时可查看目标、上下限及分配理由。新建作品即使完全留空，也会先由 AI 提出全书字数与章数供确认。

在制作台打开「篇幅」，可查看主稿已接受字数、距全书目标的差额及各章各场的预算。字数按正文非空白字符统计，包含标点。修改设置会影响后续新任务，已批准卡和历史稿保留原依据。候选稿在并入主线后计入主稿。完稿须达到有效章数、各章场已批准范围及全书下限。「全书允许少写」默认 0%，例如目标 16 万字、允许少写 5% 时，完稿至少需要 15.2 万字。超过全书目标时，制作台会显示超出字数。

「高级 · 模型调用预算」可设完整输入字符上限和最大输出 token，默认分别为 64,000 和 4,096。「设置 → 通用 API」还可填写模型服务公布的上下文窗口，写作、审稿、修订若使用不同模型可分别设置。窗口留空时，客户端能检查字符预算，并会标明实际窗口未知。写前会为当场正文、审稿和可能的修订预留容量。实际请求发出前还会再次核对，超限会保留已完成的稿件。调整预算后，点制作台「按已保存预算继续」可从阻断处接着执行。

## 阅读、修改和续章

- 点击场景打开正文；「手动修改」保存为新草稿版本。「对比」查看版本差异，「阅读」连续阅读整章。
- 新草稿需重新审稿，不会继承旧版本的通过结论。
- 已有接受正文后，追加设计从「⋯ → 制作候选与主线」建立候选；按提示复核受影响旧稿、完成新章写审，再由作者确认并入主线。
- 「成品仓库」可查看目录、制作档案、立项信息和统计，并导出已接受的 TXT / Markdown。卷导出需要已批准方案中的明确章节归属。

## 积累参考用法

1. 在「预存库」导入 TXT / Markdown，审核类型与质量；可选择仅归档原文。
2. 进入拆解队列后，可启动真实模型拆解，也可人工填写选项、用法和原文证据。
3. 逐条或批量批准、修改、丢弃；全部复核后入库。只有已批准且已入库的用法参与推荐。
4. 在「知识库」核对统计与升级候选。升级候选只是关联初筛，需人工语义核对；批准版本对新立项生效。

真实模型连续写作与文学效果尚未验收；完整语义自动升级、任意设计单步撤销/重做、EPUB 和模型费用统计属于后续工作。详细范围与测试记录见同目录的交付说明。
