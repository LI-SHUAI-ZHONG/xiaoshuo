## 数据口径和初版决定

- 原表实际为 **35 个主类型、425 个子类型**（33 份子类型分表），按原 ID 保留全部类型，数量由接口动态返回。
- 向导为九步；规格逐项列出的推荐板块为 **8 个**：genre、tone、style、narration、world、character、structure、hook。确认页不另造推荐板块。
- 推荐只来自已入库书籍中已批准且有原文定位的拆解条目。每本书同一选项计一次；三层回退后不足三项返回 null。
- 原表没有的定义、频道归属和细分类别不凭空补造；类型定义通过知识库单独维护。
- 拆解可调用已配置的真实模型，结果等待作者复核；无模型时可人工标注原文证据。不存在模板生成小说或默认推荐。
- 升级层独立存储和版本化；新书立项时冻结快照，既有书的快照保持不变。
- 首版导入 TXT/Markdown，导出 TXT/Markdown；EPUB 仍属后续版本。
