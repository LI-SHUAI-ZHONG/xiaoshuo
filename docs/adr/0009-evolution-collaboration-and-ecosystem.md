# ADR 0009：进化、沙箱、协作与生态扩展

- 状态：Accepted（由 37–42 落实）
- 日期：2026-09-24

进化闭环包括观察、假设、候选、冻结样本评估、批准或已授权政策、真实晋升、监控和回滚。
配置包通过 CAS 切换活动版本，只影响新 Run；不足样本不能称为质量提升。
代码包由独立发布器在真人批准后安装，Agent 本身没有改生产代码、权限或部署的权力。
权限、所有权、安全策略和预算上限不属于自动优化参数。

插件和生成代码在无生产凭据、宿主挂载或容器 socket 的隔离 Linux 运行环境执行，有限额和
出站白名单。缺合格隔离环境即待配置，不能用普通 Python 子进程冒充安全沙箱。
tool/agent/prompt/workflow/knowledge/content/ui-module/core-change 分别有类型与安装协议。

正文只允许同一 document_epoch 的一种写入通道。solo 使用 REST CAS；collaborative 使用
持久 Yjs updates，服务端落盘后才确认保存。切换先冻结并快照，再提高 epoch，使旧写入失效。
正式 Revision 从冻结 seq 的快照生成，协作传输层不直写 projects 的事实表。

媒体任务具有真实创建、查询、取消、失败、费用和资产归档链；外部能力不支持的动作明确拒绝。
角色视觉和分镜引用已冻结设定；结果是媒体资产，文本占位不能算图片、音频、视频或 3D。

私有市场保留包权限审核、版本依赖、授权、贡献比例、订单、退款和申诉。记账不可变，退款用
反向分录；支付状态由服务端核验事件或受审手工对账决定，不能信任浏览器 success URL。
金额为最小币种单位，比例与舍入规则固定，应付和实际已付分开。权属记录是声明和证据，
不等同法律确权。真实支付、购买、发布、账户开通均需另有具体授权。

这份 ADR 确定完整实现边界，不证明扩展已可运行。启用状态、配置、健康、验证与资料充足度
必须分别显示，最终验证见 T094–T129。
