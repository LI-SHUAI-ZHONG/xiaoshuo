## 应用与路由

`apps/studio` 使用 Next.js 16.3.4、React 19.2.8、TypeScript strict、Tailwind CSS 4.3.3、TanStack Query 5.102.8 与 Zustand 5.0.15，全部精确写入 `pnpm-lock.yaml`。

```text
/
├─ /status                                      public
└─ /workspaces                                  authenticated
   └─ /[workspaceId]                            Workspace context
      └─ /projects/[projectId]                  Project context
```

- 根路由跳转到 `/workspaces`；未认证时由认证边界呈现真实未登录状态。
- `/status` 是公开 Studio 状态页，不读取受保护业务数据。
- `[workspaceId]` 和 `[projectId]` Route Layout 分别建立作用域 Provider；Project 响应与 Workspace 不一致时拒绝渲染。
- Workspace 与 Project 列表、名称和状态都来自生成客户端，不硬编码项目、统计、进度或 Agent 在线信息。
- `ACCOS_API_ORIGIN` 仅由 Next 开发/部署代理读取；浏览器始终调用相对 `/api/v1`，源码内没有绝对 API URL。

## Provider 与状态管理边界

| 边界                  | 持有内容                                   | 明确不持有                         |
| --------------------- | ------------------------------------------ | ---------------------------------- |
| `AuthProvider`        | 当前内存会话、登录/退出注入点              | 权限角色、业务数据、持久化 token   |
| `IdentityProvider`    | `/identity/me` 验证后的身份与权限快照      | 客户端推断角色                     |
| `WorkspaceProvider`   | 当前 Workspace API 响应                    | Project 集合                       |
| `ProjectProvider`     | 当前 Project API 响应与 Workspace 归属校验 | 编辑器草稿                         |
| `StudioQueryProvider` | 身份、健康、Workspace、Project 服务端数据  | 侧栏和面板状态                     |
| Zustand `ui-store`    | 侧栏、命令区、详情面板、草稿面板宽度       | API 响应、Workspace、Project、身份 |
| `FeatureFlagProvider` | 远期 UI 能力开关；默认全部关闭             | 授权决定                           |

统一 query key 工厂位于 `apps/studio/src/lib/api/query-keys.ts`。REST 查询只经 `@accos/api-client` 的生成路径类型执行，并显式传递 Workspace header；应用源码没有直接 `fetch`。

## 页面状态与错误边界

- 未登录、无 Workspace、无 Project、无权限、未找到、API 一般失败、离线、依赖降级和加载状态可独立渲染。
- `ErrorEnvelope` 从生成的 `components` 类型映射为 Studio `ApiProblem`；401、403、404、409、503、网络失败保持不同语义，相关 ID 可安全显示。
- `error.tsx`、`global-error.tsx`、`not-found.tsx` 与 `loading.tsx` 覆盖路由、根布局、404 和 Suspense 状态。
- 健康状态按 30 秒回拉；离线使用浏览器 online/offline 事件，降级与离线都提供非颜色文字提示。
