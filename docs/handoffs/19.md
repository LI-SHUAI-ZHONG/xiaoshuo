## Studio 工作区实现

### Dashboard 与 Project

- `/` 现在跳转 `/dashboard`；Dashboard 只展示真实 Workspace ID、可访问 Project 总数、权限策略版本和逐 Project Asset 数量，不显示 Run、在线状态或伪造指标。
- `/projects` 提供真实集合、空状态和权限受控的创建入口；创建成功后进入服务端返回 ID 对应的 Project Studio。
- Project Studio 提供 Project Info、World、Characters、Timeline、Artifacts、Assets 六个容器页签。World/Characters/Timeline 复用对应 Artifact 类型；空集合明确标识未建立内容。
- Project Provider 同时核对 URL Project、响应 Project 与 Workspace，跨 Project URL 不复用当前 Project 内容。

### Writing

- `EditorPort` 与默认 `PlainTechnicalEditor` 已建立可替换边界；当前只允许技术输入，不引入富文本编辑器。
- 保存时在浏览器生成 SHA-256，并提交 `studio-input://sha256/...` 技术引用与 `If-Match` 聚合版本；不会把输入框内容描述成已持久化正文。
- Revision 列表来自 API；Context / Memory / Knowledge 来源区明确显示当前未绑定来源，Agent Task 明确留到执行 20。

### Knowledge 与 Memory

- Knowledge 展示真实 Asset、处理状态和来源，支持最小文本文件 base64 上传、创建摄取任务、轮询终态、显示 Document/校验/错误码，以及展示带 locator 与 verification status 的 Citation 检索结果。
- Memory 支持按真实 ID 读取、scope/type 前端筛选和 working/session/project 三类技术记录写入；响应展示 scope、type、内容、版本与 provenance。
- `MemoryResponse` 补齐嵌套 `provenance` 响应契约，后端契约测试、OpenAPI snapshot 和生成 TypeScript 类型已同步；没有数据库模型或迁移变化。

## 状态、安全与响应式

- 401、403、404、409、503、网络错误、加载、空集合和筛选为空继续复用统一状态组件；503 显示“服务降级”，404 不渲染被请求 Project 的主内容。
- VIEWER 的 Project/Artifact/Asset/Memory 写入口均隐藏或禁用；Playwright 另行直接调用写 API，确认服务端返回 403，前端隐藏不是授权边界。
