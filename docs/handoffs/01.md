## 固定技术基线（执行 02 输入）

- 架构：模块化单体、独立 Worker、端口/适配器、事务 Outbox。
- 前端：Next.js App Router、React、TypeScript、Tailwind CSS、TanStack Query；Zustand 仅用于本地 UI 状态。
- 后端：Python、FastAPI、Pydantic、SQLAlchemy、Alembic。
- 异步：Celery 适配器 + Redis；持久状态位于 PostgreSQL。
- 数据：PostgreSQL + pgvector、Redis、S3 兼容存储，本地 MinIO。
- 接口：`/api/v1` REST/OpenAPI 与可恢复 SSE；协同 WebSocket 延后。
- 身份：OIDC/JWT 端口、本地开发身份适配器、工作区 RBAC。
- AI：模型/工具网关、配额和审计；默认 Fake/Null Provider。
- 质量：Ruff、类型检查、pytest、ESLint、TypeScript、前端单测、Playwright。
- 可观测性：结构化日志、OpenTelemetry 接口、指标、健康与就绪检查。
- 本地/交付：Docker Compose、OCI 镜像、单节点部署说明；不引入 Service Mesh。
