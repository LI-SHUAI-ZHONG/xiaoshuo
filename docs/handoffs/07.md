## 本阶段变更

### Projects

- 新增 `modules/projects`：`Project`、`ProjectStatus`、`ProjectSettings`、`Artifact`、`ArtifactType`、`ArtifactRevision`、公开仓储端口和 `ProjectService`。
- Project 创建复用平台 IdempotencyStore；`(workspace_id, projects.create, key)` 同输入重放返回首次 Project，不同输入得到 `idempotency_conflict`。
- Project 与 Artifact 使用整数乐观锁。Project 支持 `active → archived` 软归档；归档后设置更新、Artifact 创建和资产写入都由应用策略拒绝。
- Artifact 只保存类型、标签、当前修订号和可选外部内容引用/哈希，不包含章节、世界、人物或其他创作正文。

### Assets 与对象存储

- 新增 `modules/assets`：`Asset`、`AssetVersion`、`UploadSession`、扫描/处理/上传状态、`ObjectStorage`、`ContentScanner` 和 `AssetService`。
- 新增 `MinioObjectStorage` 与 `InMemoryObjectStorage`。put/get/stat 都验证 canonical key；内存适配器支持确定性的缺失和损坏故障测试。
- 对象键固定为 `workspaces/{workspace_uuid}/projects/{project_uuid}/assets/{asset_uuid}/versions/{asset_version_uuid}`，不含用户文件名，也不接受绝对路径、反斜杠、空片段或 `.`/`..`。
- 上传默认上限 10 MiB，校验非空大小、受控 MIME/扩展组合、lowercase SHA-256、实际内容哈希、Project 内重复内容和逻辑文件名。相同 Project 内相同哈希复用已验证版本；同一 Asset 可从 v1 追加到 v2。
- 恶意内容扫描通过 `ContentScanner` Hook。当前组合根显式使用 `UnconfiguredContentScanner`，持久状态为 `not_configured`；`rejected` 阻止上传，`failed` 失败关闭，不会伪装成 clean。
- 上传在对象 I/O 前创建 UploadSession。对象写失败记为 `failed`；对象写成功但元数据/Outbox 事务失败记为 `compensation_required`，`resume_upload` 复核 key、哈希、MIME 和大小后继续提交。
- 数据库记录存在但对象缺失/损坏时，AssetVersion 标记 `missing_object`；恢复原对象且下载哈希验证通过后回到 `available`。
- 删除只有 `active → pending_deletion` 标记与 `deletion_marked_at`/`retention_until`；没有生产永久删除端口或后台清理器。

### 持久化、事件与组合

- 新增 Alembic revision `0003_projects_assets` 和六张表：`projects`、`project_artifacts`、`project_artifact_revisions`、`assets`、`asset_versions`、`asset_upload_sessions`。
- 所有业务查询显式包含 Workspace scope；项目级资源同时包含 Project scope。跨空间查询返回不可用，并通过统一 AuthorizationService 记录拒绝审计。
- 事件 schema 均为 v1：`projects.project-created`、`projects.project-settings-updated`、`projects.project-archived`、`projects.artifact-revision-created`、`assets.asset-uploaded`、`assets.asset-deletion-marked`。
- Project/Artifact/Asset 状态与事件在同一数据库事务写入；Outbox 不由领域模块直接发布。
- 组合根注册 `projects`、`assets` 生命周期模块，并注入 SQLAlchemy repository、MinIO storage、默认上传策略和未配置扫描器。HTTP 路由仍按计划留给执行 16。
