# 执行 NN 交接

## 状态与范围

- 状态：IN_PROGRESS / IMPLEMENTED_UNTESTED / BLOCKED / VERIFIED
- 对应需求R与待测T；本步实际完成内容（不要粘贴计划当成果）
- 当前下一条动作；直接前置交接

## 实际交付

- 实际文件、领域用例、持久化、API方法/路径、页面入口、Worker与事件接线
- 公共契约版本、输入输出版本、唯一owner、权限/审批政策
- 源码迁移head、新增迁移、是否实际执行（24–44必须未执行）
- 默认运行包ID/版本/hash；依赖与锁文件
- 外部配置与缺项；真实适配器已实现部分和剩余接线

## 核对与待测

- 静态核对：具体命令、结果、源码/生成物；明确不是运行测试
- 运行测试：NOT_RUN（24–44）；T编号、精确入口、所需环境、证据目录
- 未通过/未运行不得写PASS；45后方可引用实际测试证据

## 保护、恢复与下一步

- 原始材料和旧迁移hash；源码副本；无数据库修改时明确写出
- 回退所需版本与操作，不使用reset/clean删除未提交成果
- 更新进度.json与需求矩阵/实施登记；待测状态与实施状态分开
- 下一步输入和下一条可执行动作；没有人为按天等待
